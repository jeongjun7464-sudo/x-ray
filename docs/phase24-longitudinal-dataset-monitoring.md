# Phase 24 — 종단 비교·데이터셋·모니터링

## 실제 구현 범위

- 두 익명 분석 ID의 부위·양성 소견 변화 비교와 의료진 검토 상태 저장
- 촬영 방향, 해상도, 장비의 불일치·누락 시 `LIMITED` 비교 상태 표시
- 의료진 수정 결과를 익명 active-learning candidate로 저장 (`automatic_retraining=false`)
- SHA-256 기반 비식별 manifest, 중복 제거, 환자 단위 결정론적 train/validation/test 분할
- 다중 소견 라벨 승인 게이트, CSV manifest, 데이터셋 버전 저장
- 승인 검증 정답 기반 혼동행렬 인터페이스와 정답 부재 시 `NOT_MEASURED`
- 모델 버전, 체크포인트 SHA-256, 데이터 버전, 배포·성능·드리프트 상태 저장
- 의료기기 개발 문서 6종의 검토 필요 Markdown 초안 생성

## 의도적 제한

- 원본 DICOM과 환자 식별자는 데이터셋 테이블에 저장하지 않는다.
- 종단 비교는 영상 정합이나 질환 진행 진단을 수행하지 않는다.
- 수정 데이터는 자동 재학습·자동 배포되지 않는다.
- 실제 승인 검증 데이터가 없으면 정확도, 민감도, 특이도 또는 드리프트 수치를 생성하지 않는다.
- 모든 결과는 연구·교육용 보조 정보이며 의료진 확인 전 확정되지 않는다.
