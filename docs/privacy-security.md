# Privacy and security

DB에는 SHA-256 파일 해시, 형식, 크기, 모델 결과와 검토 기록만 저장한다. 환자명·환자번호·생년월일·주소·전화번호·기관명·의뢰의 이름은 저장하지 않는다. `anonymize`는 지정 태그 및 private tag를 제거한 사본을 만든다. 원본 DICOM은 영구 저장하지 않는다.

현재 MVP는 크기 제한, 안전한 인메모리 처리, 내용 기반 검증, CORS 설정, 보안 헤더, 요청 ID, 상세 예외 억제와 HMAC-SHA256 서명 세션 기반 RBAC를 포함한다. 세션 토큰은 짧은 TTL을 가지며 브라우저 `sessionStorage`에만 저장하고 서버 로그·감사 이벤트에는 기록하지 않는다. 운영 전 조직 IdP/OIDC, MFA, 중앙 폐기 목록, 사용자별 rate limiting, 안티바이러스/샌드박스, TLS, 관리형 비밀 저장소, 백업·보존정책, 침투시험과 의료기관 개인정보 영향평가가 필요하다.
