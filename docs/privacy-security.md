# Privacy and security

DB에는 SHA-256 파일 해시, 형식, 크기, 모델 결과와 검토 기록만 저장한다. 환자명·환자번호·생년월일·주소·전화번호·기관명·의뢰의 이름은 저장하지 않는다. `anonymize`는 지정 태그 및 private tag를 제거한 사본을 만든다. 원본 DICOM은 영구 저장하지 않는다.

현재 MVP는 크기 제한, 안전한 인메모리 처리, 내용 기반 검증, CORS 설정, 보안 헤더, 요청 ID, 상세 예외 억제를 포함한다. 운영 전 인증/인가, 사용자별 rate limiting, 안티바이러스/샌드박스, TLS, 감사로그, 비밀관리, 백업·보존정책, 침투시험과 의료기관 개인정보 영향평가가 필요하다.
