# X-ray AI 구축 및 분석 지원 시스템

## 한 줄 소개

X-ray/DICOM의 안전한 수집부터 부위 분류, 다중 이상 의심 소견, 불확실성, 사람 검토와 추적성까지 연결한 연구·교육용 풀스택 시스템입니다.

## 배경·대상·핵심 기능

반복적인 영상 정리와 불완전한 메타데이터 문제를 줄이되 AI를 진단기로 오해하지 않도록 설계했습니다. 의료영상 AI 개발자, 검토자와 품질관리자가 대상이며 통합 분석, 10개 소견 multi-label 계약, 안전 라우팅, 버전·감사·PDF를 제공합니다.

## 담당 업무와 기술 스택

FastAPI/SQLAlchemy/Alembic API·DB, pydicom/Pillow 전처리, PyTorch 모델 계약, React/TypeScript 뷰어, pytest/Vitest 회귀시험, Docker Compose와 추적 문서를 설계·구현했습니다.

## 문제 해결과 보안

기존 부위 분류 API를 유지하면서 버전된 `/api/v1/xray` 계층을 추가했습니다. 체크포인트 부재를 숨기지 않고 해시 기반 DUMMY를 동일 인터페이스로 만들었으며 가짜 Grad-CAM을 차단했습니다. 원본 픽셀·직접식별자는 저장하지 않고 익명 해시와 검토 전후 감사 정보만 보존합니다.

## 검증·한계·향후 계획

합성 PNG/DICOM으로 스키마, 재현성, 임계값, 품질/OOD 검토, 배치 제한, 권한·감사, 히트맵 차단을 자동 검증합니다. 임상 정확도·AUROC를 측정하지 않았고 실제 소견 모델, PACS/Orthanc, OIDC는 `NOT_CONFIGURED`입니다. 향후 허가된 데이터, 환자 단위 분할, 외부 검증과 캘리브레이션 후 승인 모델을 연결합니다.

## 면접 핵심 포인트 5개

1. 기존 API 호환성을 보존한 버전형 통합 파이프라인
2. 실제/DUMMY가 같은 계약을 쓰는 교체 가능한 ML 구조
3. 품질·OOD·불확실성·충돌을 Human-in-the-loop로 연결한 안전 설계
4. 원본 비저장, 익명 해시, 감사 로그와 모델 계보
5. 요구사항–위험–테스트 추적과 측정하지 않은 성능을 주장하지 않는 책임 있는 AI
