# 비기능 검증

성능 시험은 단일 영상, 동시 요청, 대용량 배치의 P50/P95/P99, 오류율, 처리량을 실제 실행 결과로만 기록한다. 복구 시험은 모델/DB/worker 장애, 중복 요청, 부분 배치, 롤백을 합성 failure injection으로 검증한다. 보안 시험은 잘못된 파일, 위조 MIME, ZIP 경로 조작, PHI, 권한, 감사 무결성을 다룬다.

저장소에는 시험 시나리오와 계측 인터페이스가 포함되지만 운영 규모 부하 시험과 임상 성능 수치는 없다. 실행하지 않은 결과는 PASS나 측정값으로 생성하지 않는다.
