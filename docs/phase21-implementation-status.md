# Phase 21 AI 고도화 및 의료기기 검증 구현 현황

| 구분 | 기능 | 상태 | 근거/제한 |
|---|---|---|---|
| AI 안전 | 8단계 파이프라인과 단계별 기록 | 구현 | `PipelineRun`, `advanced_ai.py`; X-ray 미확인 시 안전 중단 |
| 위치 탐지 | bounding box 인터페이스 | 부분 구현 | 기능 플래그와 COCO 좌표 계약만 제공; 학습 모델 없음 |
| 랜드마크 | 라벨 인터페이스 | 부분 구현 | 예상 랜드마크만 제공하며 추론값은 빈 배열 |
| 전처리 | 원본/min-max/z-score/crop 비교 | 부분 구현 | MLflow 기록과 전체 후보 방식은 미구현 |
| OCR | 개인정보/마커 검토 API | 부분 구현 | 모델이 없어 임의 탐지·마스킹하지 않음 |
| 라벨링 | 라벨 작업, 배정, 이중 검수, 합의, CSV | 부분 구현 | 웹 bbox 편집기, COCO export, 확대/WL UI 미구현 |
| 데이터 계보 | 입력·출력 해시와 버전 이벤트 | 구현 | 예측 단계 저장 및 조회 API |
| 재현성 | 환경·seed·버전·재실행 명령 | 구현 | checkpoint와 성능은 실제 학습 전 `null` |
| 스트레스 시험 | 7개 합성 변형과 품질 변화 | 부분 구현 | 승인 모델/정답이 없어 정확도 저하율은 미측정 |
| 알림 | 내부 DB 알림 | 구현 | 이메일·Slack 외부 전송 없음 |
| PWA | 설치 manifest와 정적 캐시 | 구현 | `/api/*`와 의료 데이터는 서비스워커 캐시에서 제외 |
| 기능 플래그 | 관리자 변경과 감사 로그 | 구현 | 헤더 기반 데모 RBAC |
| SBOM | CI 생성 구조 | 부분 구현 | CI 실행 후 산출물 확인 필요 |
| 검증 문서 | JUnit 기반 Markdown 생성기 | 구현 | PDF/DOCX 변환은 미구현 |
| RA 추적성 | URS/SRS/RISK/DES/TST 연결 | 구현 | 임상 규제 제출 문서가 아님 |
| 결함/CAPA | 등록 및 연결 | 부분 구현 | 전체 상태 전이 UI와 PMS 외부 어댑터 미구현 |
| 통합 허브 | DX/CR/MR/CT/US 라우팅 계약 | 구현 | MRI 외부 호출은 수행하지 않음 |
| 포트폴리오 | 공개 가능 UI와 문서 | 구현 | 측정하지 않은 성능 수치 없음 |

## 명시적 미구현

- 실제 YOLO/Faster R-CNN/RetinaNet/MONAI Detection, OCR, 랜드마크 모델
- MLflow 전처리 실험, DVC, 승인 모델 성능 비교와 공정성 분석
- Celery 중단·재개형 배치 추론과 결과 CSV
- 실제 모델 스트레스 정확도, calibration 및 하위그룹 성능
- 외부 이메일/Slack, 운영 OIDC/OAuth2, 의료기기 규제 승인

미구현 사유는 검증된 라벨·모델·외부 시스템·조직 정책이 없기 때문이다. 빈 모델이나 규칙 결과를 실제 AI로 표시하지 않는다.
