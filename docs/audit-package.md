# 감사 대응 패키지

## QMS 초안 패키지

기존 AuditPackage를 재사용하며 `/api/v1/qms/audit-packages`는 INCOMPLETE_DRAFT 구조 메타데이터 ZIP을 만든다. manifest에 정합성 실행 ID, 파일별 해시, 생성 시각·역할을 기록한다. 다운로드는 전체 ZIP과 내부 파일 해시를 재검증하며 기존 비인증 다운로드 경로로 QMS 패키지를 열 수 없다. 규제 제출용 전체 문서 묶음은 아니다.

QA/RA 또는 관리자가 요구사항·위험관리·데이터셋 명세·모델 카드·검증 보고서·승인/변경/CAPA 이력·추적성 매트릭스를 ZIP으로 생성한다. manifest에는 각 산출물의 SHA-256, 생성 시각, 관련 버전, 생성자 역할이 있다. 다운로드 전에 전체 ZIP 해시를 다시 계산하며 변경되면 `INTEGRITY_FAILED`(409)를 반환한다.

PDF 내용은 자동 생성 초안이고 XLSX/CSV는 구조화된 내보내기 골격이다. 규제 승인 자료로 사용하기 전 담당자의 검토와 실제 증적 연결이 필요하다.
