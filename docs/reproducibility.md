# 분석 재현성

모델 검증은 체크포인트·데이터셋·정책·환경·seed 버전을 저장하고 재시험은 실패 실행에 연결한다. 모델이나 데이터 변경은 새 전체 검증이다.

각 통합 분석은 원본 대신 익명 입력 SHA-256과 전처리·모델·체크포인트·데이터셋·임계값·라우팅·애플리케이션 버전, 실행 시각·환경, random seed를 저장한다. `GET /api/v1/analyses/{id}/provenance`로 조회하고 `compare` API로 결과 차이를 비교한다.

개인정보 보호 설계상 현재 원본 영상은 보존하지 않는다. 따라서 `reproduce`는 `RAW_INPUT_NOT_RETAINED`(409)를 반환하며 재현 완료로 표시하지 않는다. 승인된 비식별 객체 저장소가 연결된 경우에만 큐 실행을 활성화한다.
