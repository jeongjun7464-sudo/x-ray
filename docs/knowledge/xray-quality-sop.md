# 연구용 DEMO 문서

실제 의료 지침이 아니다. 품질 WARNING 또는 REJECT 결과는 사유와 입력 상태를 사람이 확인하고, 분석 결과만으로 재촬영이나 진료 결정을 내리지 않는다.

## 확인 항목

노출, 대비, 흐림, 잘림, 회전, 빈 픽셀, 해상도와 지원 범위를 확인한다.
