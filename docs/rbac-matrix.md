# RBAC 매트릭스

| 역할 | 허용 작업 |
|---|---|
| TECHNICIAN | Study 등록, 분석 요청 |
| RADIOLOGIST | Study 결과 검토, 우선순위 수정, 검증된 Grad-CAM 조회 |
| ML_ENGINEER | 모델 등록, 검증 요청 |
| QA_RA | 모델 시험·승인, CAPA 관리 |
| ADMIN | 우선순위 규칙, 배포·롤백, 사용자·연동 설정 |

역할은 데모용 `X-Role` 헤더로 확인한다. 허용되지 않은 작업은 403이며 중요 변경은 감사 로그에 기록한다. 실제 운영에는 조직 인증, 세션, MFA 및 최소권한 정책 연동이 필요하다.
